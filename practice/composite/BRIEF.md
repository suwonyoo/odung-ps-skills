# 합성 연습: 교육 배치와 이동 계획
AI 허용 준비 연습이다. 실제 평가 자료가 아니다. 구현 제한은 180분이다.

운영자는 교육 요청 CSV, 교육실 JSON, 장소 간 이동시간 CSV를 올린다. 직원은 배정된 교육 시간·교육실·이동편을 조회한다. 교육마다 한 개 교육실을 정하며, 실 수용 인원과 장비 조건을 지켜야 한다. 동일 직원/교육실의 교육 시간이 겹치면 안 된다. 이동편에는 정원 8명인 차량 두 대만 쓸 수 있다. 인원 배치, 교육실 선택, 이동편 출발 시각을 모두 고려해야 한다. 이동시간 행렬은 대칭이라고 가정하지 않는다.

우선 교육을 가능한 많이 배정하고 다음으로 총 이동시간을 줄인다. 배정하지 못한 요청의 처리 방식과 우선순위는 담당 HR에게 확인할 수 있다. 동시 요청 중 어떤 요청을 먼저 배정해야 하는지는 여기서 지정하지 않는다. 데이터셋을 바꾸는 동안 오래된 계획이 새 데이터 계획처럼 보이면 안 된다.

실행 결과는 CLI로 JSON 파일을 만든 뒤 최소 조회 화면에서 읽으면 된다. 최종 필요 파일은 app/main.py, README.md, DECISIONS.md. 포트 제한은 없으며 배포는 요구하지 않는다. 결과 JSON은 output/plan.json으로 만든다. 의존 패키지와 모델은 실제 환경의 허용 범위에서 사용한다. HR DM은 사용자가 직접 하고 답을 전달한다.
