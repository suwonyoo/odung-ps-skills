# 디자인 참조 모음

사용자가 제공한 디자인 북마크다. 아래 용도 설명은 전달받은 분류이며, 사이트별 현재 제공 범위·가격·이용 조건을 검증한 목록은 아니다.

| 참조 | 용도 | 링크 |
|---|---|---|
| Modulify Templates | 템플릿·빌드 참고 | http://modulify.ai/templates |
| Iconly | 브랜드 참조 | http://iconly.design |
| Font in Logo | 로고에 사용된 서체 참고 | http://fontinlogo.com |
| Logo To Use | 로고 참고 | http://logotouse.com |
| Landdding | 랜딩 페이지 이미지 참고 | http://landdding.com |
| Motion in Design | 모션 섹션 참고 | http://motionin.design |
| Wonderlist | Figma 디자인 참고 | http://wonderlist.design |
| WeDoFlow | 웹사이트 디자인 영감 | http://wedoflow.com |
| Ikonik | 아이콘 참고 | http://ikonik.modulify.ai |
| Paper Animation | 인터랙티브 애니메이션 참고 | http://paperanimation.ai |

화면 흐름과 공유 입출력이 정해지면 필요한 참조만 골라 사용한다. 모든 사이트를 순회하거나 새 계정·유료 서비스를 전제로 작업하지 않는다. 실제 에셋을 도입할 때 제공 페이지의 사용 조건을 확인한다.

메인 세션은 `.harness/work/main-session.md`의 디자인 인계 부분에 선택한 URL, 참고한 요소, 실제 적용 범위와 남은 작업을 짧게 기록한다. 디자인 세션은 변경 내용을 자기 worker 기록으로 전달하며 메인 기록이나 공유 명세를 덮어쓰지 않는다. 참조 탐색은 핵심 계산과 검증을 기다리게 하지 않도록 범위를 제한한다.

과제 폴더에 설치하면 이 목록은 `.harness/references/design/README.md`에 있다.
