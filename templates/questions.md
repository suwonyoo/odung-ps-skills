# 이해관계자 질의

workflow.json의 contact.mode를 따른다. DM이 없으면 문서 근거·사용자 결정으로 진행하고, 있다고 하면 사용자가 직접 질문과 답변을 전달한다. 출처를 섞거나 AI 기본값을 사람의 답변으로 기록하지 않는다.

## 대기 질문

| ID | 질문 원문 | 왜 필요한가 | 답에 따라 달라지는 것 | 미응답 시 임시 가정 | 우선순위 |
|---|---|---|---|---|---|

## 답변 기록

각 항목: ID / 사용자가 전달한 원문 / 전달 시각 / AI 해석 / 관련 요구 ID / 바뀐 모델·코드·검사 / 충돌·미확인.

원문을 짧게 바꿔 쓴 요약과 섞지 않는다. hard 규칙인지 선호인지 불분명하면 임의 가중치로 숨기지 않는다.
