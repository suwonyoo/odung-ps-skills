# Timed task workflow

When the user supplies a problem/brief and says to start, continue, or resume a hackathon task, read `.agents/skills/hackathon-start/SKILL.md` and follow its routes without requiring individual skill commands. This is the task workspace, separate from the public preparation repository.

Read actual task files and preserve their stack and submission rules. Start with rigorous intake, including combined subproblems and their shared constraints. At every phase check for material unknowns; use the manual stakeholder bridge, pause dependent work, and resume only after the copied answer is reconciled. Show phase, current task, blocker, next step and measured time/budget.

Existing task instructions and actual assessment rules take priority. Use this only for preparation or AI-permitted implementation. Stop for an active no-AI assessment. Never send HR messages or submit the assessment automatically. Do not publish this workspace's task data or work records to the preparation repository.
