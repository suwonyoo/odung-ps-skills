# 모델 명세

상태: 미작성. 예시나 가정을 확정 요구사항으로 승격하지 않는다.

## 문제와 선택

- 사용자·완료할 업무:
- 실제로 바꿀 수 있는 결정 / 고정된 조건:
- 솔버·모델 종류·고정 버전:
- 선택 이유 / 검토한 대안 / 감수한 비용:
- 실행 환경 확인 / 작은 예제 실행 근거:
- 사용자 확인이 필요한 우선순위:

| 항목 | 정의·단위·시간대 | 출처 | 누락·중복·잘못된 값 처리 |
|---|---|---|---|

- 입력 버전·해시 / 규모 / ID 관계:
- 결정변수·범위·예상 개수:
