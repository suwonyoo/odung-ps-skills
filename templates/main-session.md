# 메인 작업 흐름과 병렬 작업 인계

메인 세션이 작성·갱신한다. 디자인/보조 세션은 읽고 자기 작업을 worker 기록으로 전달한다.
대화 전체의 자동 녹취가 아니라 실제 자료·판단·변경·검사에 근거한 작업 기록이다.
이 문서의 요약보다 실제 원문·현재 contract.json·workflow.json이 우선한다.

## 최신 요약

- 마지막 갱신 / 작성 세션: 미작성
- 과제 폴더의 절대 경로:
- 목표 / 필수 산출물:
- 현재 단계 / 완료한 동작 / 진행 중인 작업:
- 실제 마감 또는 유연한 목표 / 현재 시간 계획:
- 확정된 규칙 / 아직 가정인 부분:
- 중요한 선택 / 이유 / 감수한 비용:
- 미해결 질문 ID / 영향받는 작업:
- 최근 실제 검사와 결과 / 근거 경로:
- 다음 행동 / 사용자에게 필요한 판단:

## 디자인 세션이 이어받을 내용

- 화면 흐름 / 필요한 화면과 상태:
- 디자인 참조: .harness/references/design/README.md (선택한 URL·요소·실제 적용 범위 기록)
- 현재 공유 명세: contract.json (미확정이면 초안이라고 표시)
- 읽고 확인한 계약 revision / 해시 / 확인 시각:
- 관련 원문·타입·API·예시 입력·예시 출력 경로:
- 지금 진행 가능한 화면 작업 / 근거:
- 답변 또는 코어 변경을 기다려야 하는 부분 / 질문 ID:
- 예시 데이터 사용 범위 / 실제 결과 연결 여부:
- 담당 세션별 파일 / 공용 타입·설정·의존성의 단일 담당자:
- 연결 시 확인할 정상·계산 중·실패·결과 없음 상태:

최신 상태는 STATUS.md, 세션별 파일 담당은 workers/에서 확인한다. 명세·질문이 바뀌면
이전 작업 범위를 그대로 적용하지 말고 영향부터 확인한다. 미확정된 필드나 동작은 임의로 확정하지 않는다.

## 누적 진행 기록

실제 작업이 생길 때 아래 형식으로 추가한다. 이전 기록을 지우지 않고 정정도 새 항목으로 남긴다.
매 명령이나 대화를 복제하지 않는다. 첫 자료 검토, 중요한 결정·HR 답변 반영·명세 변경,
실제 검사, 병렬 작업 시작/인계, 중단·재개 시점의 중요한 변화만 짧게 남긴다.

| 시각 | 단계·세션 | 확인한 사실·실제 수행 | 선택·변경과 이유 | 근거 경로·검사 ID | 디자인 영향·다음 작업 |
|---|---|---|---|---|---|
